# POPO 原創市集公開索引研究

研究時間：2026-08-19

## 可公開取得的資料

`https://www.popo.tw/index` 的網站搜尋表單為 `POST /search`，表單欄位包含 `name`、類型選擇，以及一個每頁變動的 CSRF 欄位。以公開頁面提交「義忍」後，未登入使用者可檢視 `https://www.popo.tw/search` 的結果；頁面會分為作家與書籍兩組結果，書籍區塊可見總筆數、作品標題、作者、最新章回、公開時間、書摘與分頁。

## Adapter 邊界

初版只收錄公開「書籍」結果，並將 `/books/<id>` 視為唯一可信的原站導流網址。資料列會保留 POPO 類型／書摘等公開 metadata，且在卡片明示「原創／付費章節依官方為準」。不讀取登入態資料、不碰 PO18、不得下載付費章節，也不會嘗試繞過 CSRF、防護或存取限制。

## 實作風險與策略

因官方搜尋採 CSRF 保護的 POST，Adapter 必須先取得公開首頁以取得當次 token，再用一般 HTTP Session 提交一次公開表單。若 token、格式或防護頁不可用，來源應回傳空結果與可讀 warning，不影響其他平台。這是純索引導流功能，無法也不應保證涵蓋全站或付費內容。

## 2026-08-19 實機觀察

使用者瀏覽器可在未登入狀態下完成「義忍」公開搜尋並顯示書籍結果；但目前沙盒對 `www.popo.tw` 的 TLS／HTTP 出站連線曾連續在十五秒內未收到資料。為了不讓此網路差異拖慢既有搜尋，POPO 在初版中是**手動啟用**的可選來源，聚合器最多等待二十秒後即回傳來源自身錯誤狀態，其餘來源結果仍會照常交付。Adapter 採用既有 Penana 所用的 curl_cffi 公開 Session，但不會用背景瀏覽器、帳號、Cookie 注入或任何規避方式補救連線失敗。
