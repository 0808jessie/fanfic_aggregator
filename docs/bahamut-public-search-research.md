# 巴哈姆特創作大廳公開搜尋研究

## 已驗證的公開入口

- 基本標籤搜尋：`https://home.gamer.com.tw/search.php?o=tag&kw=<URL 編碼關鍵字>`。
- 結果頁為公開可讀，不要求登入；頁面提供「詳細／縮圖／清單」顯示方式與公開分頁。
- 以「義忍」實測可取得公開結果，且同一結果頁可能混有小說、插畫與其他創作類型。
- 小說分類公開入口：`https://home.gamer.com.tw/index.php?page=<頁碼>&tnum=891&sm=1&vt=5&k1=2&k2=17`。該頁會在每筆結果旁明確顯示「小說」，可作為類型判定的交叉驗證來源。
- 實測在小說分類頁追加 `keyword` 參數不會套用關鍵字，仍回傳最新小說列表；因此不可將該 URL 當作關鍵字搜尋 API。

## 可解析的公開欄位

| 欄位 | 搜尋結果可見資料 |
|---|---|
| 類型 | 每筆項目旁的類型標記，例如「小說」或「插畫」 |
| 標題 | 作品標題與原文連結 |
| 作者 | 小屋作者暱稱與作者連結 |
| 摘要 | 文章開頭的公開文字節錄 |
| 更新時間 | 公開發表日期與時間 |
| 互動資料 | GP、巴幣與人氣；僅作輔助，不映射為字數 |
| 圖像 | 搜尋結果可能有縮圖，但不依賴其作為必要欄位 |

## 已驗證 HTML 結構

- 搜尋詳細頁的每筆公開結果位於 `div.HOME-mainbox1`。
- 標題及原文連結位於 `a.TS1[href*="creationDetail.php?sn="]`；相對網址須以 `https://home.gamer.com.tw/` 正規化。
- 作者與日期資料位於 `span.ST1`，摘要位於同一筆 `div.HOME-mainbox1b > p`，可保留為公開節錄。
- 縮圖位於 `div.HOME-mainbox1a img`；解析失敗時維持空值，不影響作品索引。
- 搜尋分頁使用 `search.php?page=<頁碼>&keyword=<關鍵字>&o=tag&v=3`。第一頁可省略 `page`。

## 類型圖示的保守對照

公開搜尋詳細頁的標題前有 `IMG-Cxx` 類型圖示。將已在公開小說分類頁出現的同人小說標題與搜尋結果對照後，`IMG-C08` 對應小說樣本；實測非小說的日誌樣本為 `IMG-C09`，而明示「練畫／產糧」的插畫樣本為 `IMG-C07`。初版 Adapter **僅接受 `IMG-C08`**，其他或未知圖示一律忽略。這會偏向少收錄，但避免將圖文、日誌或其他創作誤列為小說。

## Adapter 邊界

1. 僅以公開 HTTP 搜尋頁及作品公開連結建立索引，不登入、不使用背景瀏覽器，也不規避任何存取限制。
2. 關鍵字搜尋頁可能混入其他類型，且小說分類頁無法與關鍵字結合，因此 Adapter 會採保守規則：僅收錄能從公開結果明確辨識為小說的項目；無法確認類型的結果不納入小說索引。
3. 巴哈姆特搜尋結果不提供可靠作品總字數或章節總數，因此欄位維持空白，不以人氣、GP 或巴幣猜測字數。
4. 若公開頁回傳防護頁、限制頁或無法解析的結構，Adapter 應回報單一來源警示並提供官方搜尋連結，而不影響其餘平台。
