# Fanfic Atlas 視覺稽核

## 改版前觀察

桌面首頁原有清晰的工程圖紙語彙，但大型英雄標題、裝飾圖、搜尋列與初始空狀態同時競爭注意力。搜尋、來源健康與保存工具雖已具備，工作流的順序不夠直觀。

## 改版後首屏檢查

新版首屏將「FIND THE RIGHT THREAD」縮為明確的搜尋主張，右側 `QUERY TRAJECTORY` 直接說明輸入、五個來源與私藏筆記的連續路徑。搜尋 dock 成為首要操作面，並保留 Filters、強制更新與 Run Search 控制。

## 後續驗證點

1. 來源健康狀態需維持比結果卡更早且可見的順序。
2. 桌面與手機都需讓搜尋輸入與執行按鈕保持首屏可達。
3. 閱讀清單和 CP 詞庫的 LocalStorage 操作不可因樣式改動而退化。
4. 保留紙質底、資料網格、藍色為即時資料訊號與珊瑚色為註記訊號的系統角色。
